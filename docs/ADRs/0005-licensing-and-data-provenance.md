# ADR 0005: licensing and provenance

- **Status:** Adopted for initial screening
- **Date:** 2026-10-19

The remote repository already contains GPL version 3 text; retain GPL-3.0 as the current project license. Record the exact SPDX interpretation with the project owner before publishing a release. Do not import code, recipes, wiki-derived data, or assets solely because their upstream repository is public. Record exact revisions, paths, hashes, notices, and terms. Treat external API data terms separately from source-code licenses. Bazaar Calc's own license names CC BY-NC-SA 3.0 exceptions for specific wiki-derived files; exclude those from reuse absent a deliberate compatible decision.
